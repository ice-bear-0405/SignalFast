# Signal 快传（SignalFast）

> 局域网内两台电脑免安装直连互传文件 —— 不经任何服务器，数据不出内网。

跨设备传文件还在用微信？文件要经过第三方服务器，敏感资料不放心，大文件还压缩画质。**Signal 快传**让两台电脑在同一个局域网内（同一 Wi-Fi / 网线直连 / 一台开热点）自动发现对方，点对点直连传输，千兆网线下 1GB 文件约 9 秒。

## 特性

**传输**
- 🚀 设备自动发现（UDP 广播 + 单播回执互通，双网卡电脑也能互认 + 手动 IP 添加）
- 📁 文件 / 文件夹全速传输，多连接并行 + 磁盘预读流水线
- 🧩 大文件分段并行：64MB 以上单文件自动拆段多连接并发，接收端合并进度，总速度更快
- 🔍 每个文件自动 MD5 校验，确保内容一致
- 📊 实时速度条：当前速度 / 百分比 / 剩余时间
- ⏸ 任务级控制：暂停 / 继续 / 取消（发送端和接收端均可操作），暂停可任意时长（实时信令通知对方，不再受等待超时限制），取消后自动清理对方电脑上的半成品文件
- 📼 断点续传：中断后重发同一文件自动从断点续传，只传剩余部分，完成后仍做完整 MD5 校验
- 📂 点击已完成任务行，直接打开文件所在文件夹
- 💬 文字消息同步，对方收到后自动复制到剪贴板
- 🔁 同名文件自动重命名，不会覆盖已有文件

**安全**
- 🔒 可选 TLS 加密传输（HTTPS 同款技术）：6 位一次性验证码 + HMAC 校验，验证码本身不经网络，错误验证码直接拒收
- 🛡️ 全程设备直连，不经过任何第三方服务器

**便捷**
- 📱 手机网页互传：电脑内置局域网网页服务，手机扫码即用收发文件（无需安装 APP）
- 📶 一键热点：没有路由器也能传（引导打开系统热点）
- ⚙️ 保存目录、自动接收、开机自启均可配置
- 🛡️ 一键放行防火墙（无需手动改规则）
- 📜 传输历史：设置窗口查看最近 200 条传输记录
- 📋 传输日志按天记录，问题可追溯

## 快速开始

### 方式一：下载打包好的程序（推荐）

前往 [Releases](../../releases) 下载：

| 版本 | 适用 |
|------|------|
| `Signal快传.exe`（单文件版） | 单文件拷贝方便；个别电脑启动时解压临时目录被拦截，请改用文件夹版 |
| `Signal快传-文件夹版.zip` | 解压后直接运行，不用临时目录，**兼容性最好** |

支持 Windows 7 SP1 及以上（64 位），免安装。

### 方式二：从源码运行

```bash
pip install -r requirements.txt
python main.py
```

要求 Python 3.8+（源码兼容 Python 3.8，可运行于更高版本）。

### 方式三：自行打包 exe

```bash
pip install pyinstaller
pyinstaller --onefile --windowed --icon icon.ico main.py
```

### 首次运行（重要）

1. 双击运行，若弹出"Windows 已保护你的电脑"，点"更多信息"→"仍要运行"（程序未做商业签名）
2. **首次运行会弹出防火墙询问框：勾选"专用网络"和"公用网络"两项后点"允许访问"**——不允许的话将搜索不到对方设备
3. 在【设置】中选择接收文件的保存目录（未设置时对方发来的文件会被拒收并提醒）

## 安全性说明

- 传输在两台电脑间点对点直连完成，任何数据不经第三方服务器
- 加密传输使用 Python 内置 TLS 模块建立加密通道（AES-256-GCM 套件），服务端发随机挑战、客户端用验证码派生密钥回 HMAC 应答，验证码全程不经网络
- 程序内嵌的 TLS 证书为发布时生成的**自签名传输证书**（`core.py` 中以 base64 内嵌），仅用于建立加密通道，与任何网站/账号无关
- 普通传输为明文直连（同内网环境）；敏感文件建议使用加密传输

## 常见问题

**搜索不到对方设备？**
确认两台电脑在同一网络且首次运行时防火墙点了"允许访问"；跨网段时用左下角【手动添加】输入对方 IP。

**发送提示"无法连接 / 等待确认超时"？**
大概率是对方电脑防火墙未放行，在对方电脑上点【设置 → 一键放行防火墙】。

**单文件版启动报"could not create temporary directory"？**
启动时解压临时目录被公司终端管控/杀毒软件拦截，改用文件夹版；或联系 IT 加白。

**速度没到预期？**
同一 Wi-Fi 受路由器/AP 限制属正常；跨 AP 的 Wi-Fi 环境建议网线直连；机械硬盘也是常见瓶颈。

**旧版本升级后要注意什么？**
v1.9 新增暂停/取消通知信令端口（UDP 54544），升级后在两台电脑各执行一次【设置 → 一键放行防火墙】；建议双方同步升级，一新一旧仍可正常传输（协议向后兼容）。

更多问题见 [docs/使用说明.txt](docs/使用说明.txt)。

## 已知限制

- 仅支持 Windows（热点/防火墙功能依赖 netsh；界面基于 PyQt5）
- 加密传输需要双方都是本版本及以上（使用独立的加密端口）
