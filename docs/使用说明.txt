  Signal 快传 v1.9 - 局域网全速传输工具 使用说明
════════════════════════════════════════════════════

【这是什么】
两台电脑在同一局域网（同一网段 / 网线直连 / 一台开热点另一台连接）时，
自动发现对方设备，互传文件、文件夹和文字消息。
全程设备直连，不经过任何服务器，数据不出内网。
理论速度：千兆网线直连约 110 MB/s（1GB 文件约 9 秒）。

【两个版本，按需选】
· 单文件版：Signal快传.exe，单个文件最方便拷贝。
  注意：启动时需先解压到系统临时目录，个别电脑会被拦截（见文末常见问题）。
· 文件夹版：Signal快传-文件夹版.zip，解压后得到 SignalFast 文件夹，
  双击其中的 SignalFast.exe 即可，不依赖临时目录，兼容性最好。
  ★ 单文件版报错“could not create temporary directory”时，请改用文件夹版 ★

────────────────────────────────────────
【第一步：首次运行（重要，必看）】

1. 把 Signal快传.exe 拷到两台电脑上，双击即可运行（免安装）。
2. 可能弹出“Windows 已保护你的电脑”（SmartScreen）：
   点“更多信息”→“仍要运行”。（软件未做商业签名，属正常）
3. 首次运行 Windows 会弹出防火墙询问框（最关键的一步！）：
   ★ 必须勾选“专用网络”和“公用网络”两项，再点“允许访问”★
   不允许的话，将搜索不到对方设备、也无法收发文件。
4. 接收的文件默认保存到“桌面\Signal快传接收”，可在【设置】里改。

────────────────────────────────────────
【日常使用】

■ 传文件 / 文件夹
  1. 两台电脑都打开 Signal 快传，几秒内左栏会自动出现对方设备；
  2. 点击选中对方设备；
  3. 把文件/文件夹拖进右侧虚线框（或点“选择文件”）；
  4. 点【📤 发送文件】即发送，对方弹窗点“接收”即开始传输；
     界面右上实时显示当前速度 / 百分比 / 剩余时间。
     多个文件时自动开启多连接并行传输，速度更快。

■ 传输任务管理
  · 任务列表中正在传输的任务行右侧有操作按钮：
     ⏸ 暂停 / ▶ 继续 / ✕ 取消，发送端和接收端都可操作；
  · 暂停可以持续任意时长（v1.9：暂停/取消会自动通知对方，
     不会再被超时断开），点“继续”从断点接着传；
  · 传输中途取消后，对方电脑上的半成品文件会被自动清理；
  · 点击已完成的任务行，可直接打开文件所在文件夹。

■ 断点续传（v1.9 新增）
  · 传输中断（取消、暂停后退出程序、断网）时，已传部分会保留；
  · 重新发送同一个文件时，软件检测到接收目录里有上次半成品，
     会自动从断点继续，只传剩余部分；
  · 传完后仍做完整 MD5 校验，结果与一次性传完完全一致。

■ 大文件分段并行（v1.9 新增）
  · 单个大文件（64MB 以上）自动拆成多段并行传输，
     多文件之间不再互相等待，总速度更快；
  · 接收端进度按全部文件合并计算，无需关心内部细节。

■ 文件重复接收保护
  对方发来的文件与已有文件同名时，自动改名为“文件名(1)”等
  不会覆盖原有文件。

■ 加密传输（敏感文件推荐）
  1. 选好文件后点【🔒 加密传输】，软件生成 6 位一次性验证码；
  2. 当面或用电话把验证码告知对方；
  3. 对方弹窗中输入验证码后点“🔒 解密接收”；
  4. 文件走 TLS 加密通道传输（HTTPS 网页同款的主流加密技术，
     AES-256-GCM 加密套件 + 证书校验），验证码用于接收端身份校验，
     验证码本身不经网络——不知道验证码的连接一律被拒收，
     错误验证码会直接中止。任意电脑 100% 可用（零外部依赖）。
  （普通传输为明文直连，速度稍快；加密传输适合敏感数据）

■ 传文字 / 消息同步
  右侧输入框输入文字，回车或点【发送文字】。
  对方收到后会自动复制到剪贴板并弹窗提示（不用再发微信同步验证码）。

■ 手动添加设备
  v1.10 起设备发现支持“回执互通”：只要一方能收到另一方的广播，
  双方就会互相出现在列表中。典型场景——台式机网线上网同时开热点、
  笔记本连热点：此前台式机（双网卡）搜得到笔记本、笔记本却搜不到
  台式机，现在会自动互认，一般无需再手动添加。
  如果左栏仍没出现对方（常见原因：两机不在同一网段，广播完全不通），
  在左下角输入对方 IP 点【手动添加】，对方在线即可出现。

■ 手机互传（手机 ↔ 电脑，v1.11 新增，无需安装 APP）
  1. 点顶栏【📱 手机互传】，弹出二维码（每个网络一个）；
  2. 手机连接与电脑同一网络（同一 Wi-Fi / 本机热点），
     用手机相机或浏览器扫码，进入网页；
  3. 手机 → 电脑：在网页中选文件上传，自动存入电脑接收目录，
     电脑任务列表同步显示“来自 📱 手机网页”；
  4. 电脑 → 手机：在弹窗中点【➕ 添加文件】把文件共享给手机，
     手机页面即可点击下载（列表 5 秒自动刷新）；
  5. 网页地址含随机令牌，局域网内其他设备无法访问，安全无忧。
  注：网页服务默认开启，可在【设置】中关闭；
     端口 54550 在防火墙放行段内，无需额外放行。

────────────────────────────────────────
【一键热点（没有路由器也能传）】

点顶栏【📶 一键热点】：
■ 方式一：启动热点（需管理员权限，UAC 弹窗点“是”）
  在热点电脑启动后，另一台电脑连接该 Wi-Fi（密码见弹窗），
  两边打开 Signal 快传即可自动发现对方。
  注：部分较新网卡（Win10/11 常见）不支持此方式。
■ 方式二：不支持时点【打开系统热点设置】
  一键跳到 Windows 自带“移动热点”开关，效果相同。

────────────────────────────────────────
【设置项】

点顶栏【⚙ 设置】：
  · 设备名称：修改自己在对方列表里显示的名字
  · 保存目录：接收文件存放位置（首次使用必设；
    未设置时对方发来的文件会被自动拒收并提醒设置）
  · 自动接收：勾选后对方发文件不再弹窗确认（信任的内网环境可开）
  · 开机自动运行：勾选后开机即后台就绪（最小化到右下角托盘）
  · 【传输历史】：查看最近 200 条传输记录（接收记录可双击打开文件夹）
  · 【关于】页：查看版本历史与各版本更新内容

关闭窗口 = 最小化到托盘常驻；彻底退出：右键托盘图标 → 退出。

────────────────────────────────────────
【日志与防火墙（定位问题用）】

· 日志：设置窗口 →【📂 打开日志文件夹】，按天自动记录，
  发现设备、连接、握手、传输、校验、异常全部在案；
  出问题时把当天的 signal.log 发给开发者即可定位。
· 防火墙：设置窗口 →【🛡 一键放行防火墙】（UAC 点“是”）：
  放行 TCP 54546-54565、UDP 54545、UDP 54544 和本程序，
  需在【每台】使用电脑上执行一次。
  发送提示“无法连接”或“等待确认超时”时，多半是对方电脑未放行。
  v1.9 新增暂停/取消通知信令端口（UDP 54544），
  从 v1.8 及更早版本升级后请重新执行一次放行。

────────────────────────────────────────
【常见问题】

Q：单文件版启动提示 “could not create temporary directory”？
  单文件版启动时要先解压到系统临时目录，此提示说明该步骤被拦，常见原因：
  1) 公司终端管控 / 杀毒软件禁止未知程序在临时目录解压；
  2) TEMP 环境变量被改或目录无写权限。
  → 解决：改用【文件夹版】（解压 Signal快传-文件夹版.zip 后运行），
    文件夹版完全不用临时目录，可绕开此问题。
  → 若文件夹版的 exe 也被管控软件拦截（提示病毒/已删除），
    需联系单位 IT 把该软件加入信任白名单。

Q：发送提示“失败: timed out / 无法连接 / 等待确认超时”？
  1) 看任务表状态列括号里的阶段提示；
  2) 大概率是【对方电脑】防火墙未放行 → 在对方电脑上
     点【设置→一键放行防火墙】；
  3) 确认对方软件在运行且未卡死（可重启对方软件）；
  4) 仍不行 → 双方各自点【设置→打开日志文件夹】，
     把当天日志发出来对比定位。

Q：加密传输时对方说解密失败？
  验证码输入错了，请核对 6 位验证码后重新发送（每次发送验证码会重新生成）。

Q：点加密传输提示“对方版本过旧”？
  加密传输需要两台电脑都更新到 v1.7+（新版本使用独立的加密端口），
  请先在对方电脑上完成更新。

Q：旧版本升级后需要注意什么？
  1) v1.9 新增暂停/取消通知信令端口（UDP 54544），升级后请在
     两台电脑各执行一次【设置→一键放行防火墙】；
  2) 建议两台电脑同步升级；一新一旧时仍可正常传文件
     （协议向后兼容），但暂停/取消实时通知在旧版一端不生效。

Q：旧版在桌面自动建的“Signal快传接收”文件夹还在？
  新版已不再自动创建任何文件夹，旧的空文件夹可以自行删除。

Q：看不到对方设备？
  1) 检查两台电脑是否连的同一个网络（同一路由器/热点）；
  2) 首次运行的防火墙弹窗是否点了“允许访问”？
     补救：控制面板→防火墙→允许应用通过防火墙→勾选 Signal快传；
  3) 若两台电脑不在同一网段（如 192.168.x.x 与 10.x.x.x），
     广播发现不通，请用【手动添加】输入对方 IP；
  4) 还不行就互 ping 一下对方 IP，ping 不通则是网络隔离，需先解决网络。

Q：传输速度没到预期？
  同一 Wi-Fi 下受路由器限制属正常；网线直连最快。
  机械硬盘也是常见瓶颈（约 100-150 MB/s 封顶）。

Q：安全吗？
  传输在两台电脑间直连完成，不经任何第三方服务器；
  每个文件传输后自动 MD5 校验；接收前需确认（自动接收可关闭）。

【系统要求】

Windows 7 SP1 及以上（含 Win8/10/11），64 位系统。
Win7 需已安装 SP1 与系统基本更新补丁。

【源码说明】
“源码”文件夹内含全部 Python 源码（兼容 Python 3.8），
core.py=传输核心，ui.py=界面，hotspot.py=热点，test_core.py=自动化测试。
如需重新打包：pyinstaller --onefile --windowed --icon icon.ico main.py
